# Gokul's Astrological Insights — Frontend

Deterministic, mathematically rigorous Vedic and KP Krishnamurti Paddhati astrology application powered by the XALEN astronomical engine.

## Overview

- **Brand**: Gokul's Astrological Insights
- **Framework**: Next.js 16 (App Router) with React 19 and Tailwind CSS
- **Design System**: Warm ivory/cream background, deep navy typography, restrained antique-gold accents
- **Bilingual Localization**: English and Tamil (தமிழ்)
- **Calculations**: Geocentric sidereal planetary coordinates, Lahiri & KP Ayanamsas, South Indian and North Indian chart visualizations, Vimshottari Dasa hierarchy, and KP 249 cuspal sub-lords.

## Getting Started

Run the development server:

```bash
npm run dev
```

Run test suite:

```bash
npm test
```

Run type check and lint:

```bash
npm run type-check
npm run lint
```

Build for production:

```bash
npm run build
```
